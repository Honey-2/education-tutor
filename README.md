# AI Education Tutor

## Overview
This project is an AI-based education tutor designed to help students understand concepts easily. It uses context filtering to provide relevant and accurate answers while reducing unnecessary data.

## Features
- Provides clear and simple explanations
- Uses context filtering for efficient responses
- Reduces token usage and improves performance
- Supports multiple subjects

## Tech Stack
- Python
- HTML, CSS, JavaScript
- OpenAI API

## Objective
The goal of this project is to make education accessible and efficient, especially for students in remote areas.

## How it Works
The system takes user input, filters only important context, and sends it to the AI model to generate accurate responses quickly.
